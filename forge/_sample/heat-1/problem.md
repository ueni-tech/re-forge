# [heat-1] キー・バリューキャッシュ

## 背景

同一キーに対する重い処理（設定オブジェクトの構築・パース結果など）を1回だけ実行し、以降は共有インスタンスを返したい。レガシーでは `var cache = {}` になりがちで、テストしづらい。

## やること

`createCache` を実装する。値の生成はキャッシュ側ではなく、呼び出し側が `get` のときに `factory` で渡す。

## 受け入れ条件

- `get(key, factory)`: キーがキャッシュ済みなら `factory` を呼ばず、保存済みの値を返す
- 未キャッシュなら `factory()` を1回呼び、結果を保存して返す
- `delete(key)`: 該当エントリのみ削除する（次回 `get` で `factory` が再実行される）
- 別キーは互いに干渉しない
- `createCache()` を2回呼んで作ったインスタンスは、状態を共有しない

## 型

```ts
function createCache<V>(): {
  get: (key: string, factory: () => V) => V;
  delete: (key: string) => void;
};
```

## 実装者が決めること

受け入れ条件を満たす範囲で、次は任せる。

- `factory` が `undefined` を返したとき、「キャッシュ済みの undefined」と「未キャッシュ」をどう区別するか
- 状態をクラスに置くか、クロージャに閉じ込めるか（シグネチャはファクトリ関数）
