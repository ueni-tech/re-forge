## 自分の契約と比較する観点

### 在庫(3)優先の UX 意図

同色ボタンに「この色のいずれかの SKU が在庫ありなら在庫表示」——**楽観的に購入可能に見せる** ビジネスルール。全 SKU 在庫切れなら先頭行のステータス（品切れ等）。

### 先頭行 fallback

複数行あるが在庫なし → 配列順の先頭。データ定義上の順序に依存。**仕様として明示** しておく必要がある。

### string 返却

DOM の `dataset` は文字列。数値のまま返すと暗黙変換に頼る。**境界で string 化**。

## 観察ポイント

集約ルールはフィルタと独立。**ルール変更**（例: 最悪値優先）が来たとき、heat-2 だけ差し替えればよい。
